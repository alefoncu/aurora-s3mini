# Aurora S3 Mini

A minimalist, colourful, 2026-style redesign of a **Samsung Galaxy S3 Mini (GT-I8190N)** running **LineageOS 14.1 (Android 7.1.2)**: launcher, lock screen, status bar, notification shade, boot animation, icons, camera, system fonts and an automatic day/night mode — all built without patching the boot image and without touching the original system APKs.

> Personal project for one very old device (Cortex-A9 @ 1 GHz, 800 MB RAM). Everything is device- and ROM-specific and **modifies `/system`**. Read [Safety](#safety-and-reverting) before copying anything.
> Inspired by flat mobile design; contains no third-party artwork — every icon, wallpaper and animation is generated by code in this repo. Not affiliated with Samsung, Apple, Google or the LineageOS project.

## How it works (the interesting parts)

- **Static overlays (RRO) in `/system/vendor/overlay`.** Android 7.1 has no overlay manager, but anything in that folder is a static overlay. Each stock app gets a tiny overlay APK (colours, dimensions, vector icons, themes). `values-night/` variants are compiled by aapt2 and picked up when the system night mode changes.
- **Framework overlay.** Overlays targeting `android` are loaded by the native AssetManager (`/data/resource-cache/overlays.list`), so accent colours apply system-wide.
- **SystemUI overlay.** Status bar and quick-settings icons are regenerated as thin vectors by [`tools/gen_icons.py`](tools/gen_icons.py); the QS panel and tiles are glass drawables.
- **Day/night.** [`tools/device/daynight.sh`](tools/device/daynight.sh) runs from `/data/local/userinit.sh` (LineageOS `init.d`), computes day/night from the month and hour and calls `service call uimode 4 i32 1|2`; it also swaps the wallpaper through a tiny helper activity in the launcher. Override with `settings put system ios_theme_mode auto|day|night`.
- **Launcher** (`launcher2/`): plain Java, no support library. Icons are drawn in code from a line-glyph set ([`Glyphs.java`](launcher2/src/com/scratch/ios7launcher/Glyphs.java)) on gradient squircles.
- **Camera** (`camera/`): `android.hardware.Camera` + a software H.264/AAC recorder (`MediaCodec` + `MediaMuxer`), because the device's hardware H.264 encoder cannot start (`OMX.ST.VFM.H264Enc` error -1010).
- **Root without touching the ramdisk.** The base setup uses LineageOS's `addonsu` (installs `/system/xbin/su` only). Magisk-patching `boot.img` hangs this kernel; do not try it.

## Lessons learned (each cost a crash or a reboot)

1. **Notification card backgrounds must be opaque.** A translucent `notification_material_background_color` throws `background can not be translucent` in SystemUI, and every app that posts a notification is killed with `Couldn't expand RemoteViews`.
2. **Never override `status_bar_icon_drawing_alpha`** with `<item type="dimen" format="float">`: `PhoneStatusBarView` fails to inflate and SystemUI crash-loops.
3. **File-based resources (`res/anim/*`) in a framework overlay break `system_server`** (`FileNotFoundException res/anim-v1/...`) and leave the launcher black. Window animations cannot be overlaid on 7.1.
4. **An overlay style cannot reference the overlay's own resources** (`@color/…` → `Resource ID not found` in the app). Use literals or target resources.
5. **Animated vectors (torch, rotation, airplane, location) depend on group names and path morphing** — replacing them is risky; leave stock.
6. **Hard-coded text colours in layouts cannot be changed by an overlay.** Night variants of such apps give black-on-dark text; only own apps can do real dark mode.
7. **`WallpaperManager.setStream` can fail with "Invalid wallpaper data" on this ROM; `setBitmap` works.**
8. **Hardware H.264 encoder is broken** (`OMX.ST.VFM.H264Enc`), and removing it from `media_codecs.xml` makes `MediaRecorder` hang; encode in software with `MediaCodec`.
9. **If the home app crashes Android asks which launcher to use**: `cmd package set-home-activity com.scratch.ios7launcher/.HomeActivity`.
10. **`adb screencap` shows black for the camera viewfinder**; judge the preview on the device itself.
11. Boot animation frames can be small and centred with a solid background colour (`p 1 0 part0 #14123A` in `desc.txt`) — much lighter than full-screen frames.

## Build and install

Prerequisites (macOS shown): JDK 17, Android SDK platform 25 and build-tools 30.0.3, `adb`, a rooted device with `/system` remountable. The scripts assume the repository lives at `~/ios-reskin` and sign with the standard debug keystore (`~/.android/debug.keystore`).

```bash
adb pull /system/framework/framework-res.apk work/      # needed once, to compile overlays

# overlay APKs (one per target package)
tools/build_overlay.sh <Name> <target.package> work/<dir>
# then install into /system/vendor/overlay and reboot:
adb push out/<Name>Overlay.apk /data/local/tmp/
adb shell su -c 'mount -o remount,rw /system && cp /data/local/tmp/<Name>Overlay.apk /system/vendor/overlay/ && chmod 644 /system/vendor/overlay/<Name>Overlay.apk && mount -o remount,ro /system'
adb reboot

tools/build_launcher.sh      # builds and installs the launcher
tools/build_camera.sh        # builds and installs the camera
tools/build_phone.sh         # builds and installs the phone app
python3 tools/gen_icons.py   # regenerates the SystemUI thin icon vectors

# wallpapers and boot animation
java wallpaper/MakeWallpaper.java wallpaper/aurora.png
java boot2/MakeBoot.java boot2/pkg && (cd boot2/pkg && zip -0 -r ../bootanimation.zip desc.txt part0 part1)

# day/night scheduler
adb push tools/device/daynight.sh /data/local/ios/ && adb push tools/device/userinit.sh /data/local/
```

## Safety and reverting

- Overlays are plain files: delete the APK from `/system/vendor/overlay/` and reboot (from TWRP if the phone does not boot).
- Back up before changing system files (`fonts.xml`, `bootanimation.zip`, GravityBox prefs). Originals are **not** in this repo.
- Keep `adb` working: a SystemUI crash loop does not stop `adb`, so you can always remove the offending overlay.
- Always verify after each change: reboot, `sys.boot_completed=1`, no `FATAL EXCEPTION` in `adb logcat`.

## Repository layout

```
launcher2/    launcher (Java, no AndroidX): home, search, glyph icons, helpers for wallpaper and test notifications
camera/       camera app (photo + software video recorder)
phone/        phone app (keypad, recents, contacts; follows day/night)
work/         overlay sources: app/<app>/res/values{,-night}, sysui/ (vector icons), frame/ (framework)
tools/        build scripts, icon generator, day/night helpers, scheduler (tools/device)
wallpaper/    wallpaper generators (Java 2D) and the two JPEGs
boot2/        boot animation generator
docs/         design tokens, engineering notes
```
